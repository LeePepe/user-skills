# macOS Status Bar Popover

## slot: macos-statusbar-popover

Use `Strata-Core` for the fixed 380pt popover. Apply padding before the fixed
frame. Use a 2-up Bento grid with equal-height cards, compact `K/M/B`
telemetry, `28x28pt` pointer targets, and top-trailing actions. Keep card
content solid and reserve floating material for functional chrome.
