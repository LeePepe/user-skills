# Dual-Entry Design Flow Architecture & 4 Anti-Explosion Valves (`L1` Single Source of Truth)

This document defines the unified architecture connecting **Entry A (Ingest & Stockpile: `A0..A4`)**, the **4 Progressive Shared Asset Tiers (`Tier 0..3`)**, and **Entry B (Consume & Design Delivery: `B0..B4`)**. Run `python3 skills/my-designer/scripts/verify_design_cases.py flow-map` at any time for a live JSON inventory of commands, card counts, and context-budget health.

## 3. The 4 Anti-Explosion Physical Valves (Context Budget Guarantees)

1. **Valve 1 · Zero-Token Code Sinking (`Tier 2 -> Tier 3`)**:
   - Deterministic prohibitions (`UIScreen.main`, `userInterfaceIdiom == .phone`, `LazyVStack` leaf `if` filtering, AppKit `mouseDown` `nextEvent` loops, `sessionWillBegin` modals) live as compiled regexes in `verify_design_cases.py` (`shared-ci design_contract.py` & `DC-*`). They cost **0 LLM tokens** during design and fire only when violated during `shared-ci --audit-code`.
2. **Valve 2 · 3D Coordinate Slicing (`Platform × Dimension × Container`)**:
   - `verify_design_cases.py route` intersects `--platform`, `--dimensions`, and `--container` to slice `plan_c_active_cases`, `hig_files_to_load`, and external skill packages (`shipswift.focused_packages`, `avdlee.focused_files`, `genjutsu.focused_files`). Unrelated packages (e.g. `SWChart` when `chart-dataviz` is inactive) are filtered out of focus.
3. **Valve 3 · Hard Slot & Line Caps (`Top-3` & `<=130` Lines)**:
   - `vault-search` defaults to `--top 3` cards in design flows; every Tier 2 `L1` reference file in `skills/my-designer/references/*.md` is strictly capped at **`<= 130` lines**; `defect-cases/index.json` is capped at **`<= 15` active cases** (older/superseded cases move to `archived_templates`).
4. **Valve 4 · One-In, One-Out Native Compaction**:
   - When a new Apple OS primitive supersedes a manual layout workaround (e.g., `.rect(corner: .containerConcentric)` replacing manual `innerRadius = max(4, outerRadius - padding)` math, or `.alignmentGuide` pin-flip replacing `GeometryReader` badge measurement), compact the old rule in-place rather than stacking both.
