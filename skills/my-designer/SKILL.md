# my-designer — Entry B: Product Design, Modernization & Visual Traceback (`B0..B4`)

I'm using the my-designer skill (as design lead, **Entry B** of [design-flow-architecture.md](references/design-flow-architecture.md)). This is a handoff-only capability covering both brand-new UI and existing UI modernization (**No Code Demo** — never create a `Prototype/` directory). Author the implementation-ready `design.md`/`spec.md` handoff and receipts; the downstream `Writer` implements **directly in the product or `shared-design-system` code**, never a throwaway demo. For external inspiration/palette ingestion (`Entry A`), use [../design-studio/SKILL.md](../design-studio/SKILL.md).

## Sub-mode 1 · Phase 0 Route, Spec & Modernization (`B0..B3`)
1. **B0 · Direction-Lock**: Choose one equal first-class platform (`desktop`, `mobile`, `web`) and 1–4 dimensions (`color-palette`, `visual-style`, `component`, `chart-dataviz`, `glass-material`, `motion-interaction`, `layout-navigation`, `typography-copy`). For a known direction, require a reference app/screenshot, explicit direction, and anti-patterns; lock one `VS-*` + `CL-*` + `X-Y-Z` + `AppTheme` coordinate set before authoring `design.md`.
2. **B1/B2 · Route & Four-Variant Exploration Gate**: Route Top-3 through [routing-index.md](references/routing-index.md), [taxonomy-v2.json](references/taxonomy-v2.json), [vault/](references/vault), and [toolchain-20-matrix.md](references/toolchain-20-matrix.md); use [remotion-video.md](references/remotion-video.md) only for `Video/Offline`. Never create throwaway `Prototype/` code inside product repositories. **Native Apple (`desktop`/`mobile`) SwiftUI Exploration Iron Law**: For iOS/macOS native SwiftUI (`--platform mobile|desktop`), `v01..v04` variant & motion previews MUST exclusively use the **Local Native 120Hz SwiftUI Preview Host (`PreviewHostKit` + Xcode `#Preview`)**; Web HTML/CSS approximations or low-fps MP4 video galleries (`r5-todo-swiftui-preview` style on `leepepe.github.io/demos/`) are strictly forbidden! Web Choosers (`scaffold-gallery` / `demos/<goal>/`) are reserved for **Web frontend (`--platform web`) or static card/graphic projects**. Run the four-candidate Exploration Gate (1–3 rounds) before freezing `design.md`: `scaffold-gallery --mode screen --count 4` creates v01..v04 candidates (`--count 10` supported for breadth/depth studies); each must be independently designed (no Python batch-scripted clone shells). Separately, `scaffold-gallery --mode app-nav` creates four bespoke full-app navigation schemes from target domain, screens, journeys, and action frequency via four complete `--app-flows-json` (path or JSON) schemes; `--app-screens`/`--app-context` alone never invent architectures. These are graph-driven app01..app04 demos, never fixed templates; defaults are only starter skeletons when no custom input is supplied. Record anti-patterns and ask the Owner before freezing AppTheme/design.md.
3. **B2/B3 · Freeze & Author**: After selection, freeze one shared `AppTheme` set (colors, spacing, font sizes, native conventions) and `design.md` before direct production implementation. Apply [interaction-layering.md](references/interaction-layering.md), [appearance-ledger.md](references/appearance-ledger.md), [breathing-and-clarity.md](references/breathing-and-clarity.md), [modernization-dimensions.md](references/modernization-dimensions.md), Plan C [defect-cases/index.json](references/defect-cases/index.json), and executable [eval-cases.json](references/eval-cases.json); use existing Dim 1/4 consistency rules rather than duplicating them. **Subtractive Mandate & In-Place Unfold Gate (`DC-014` / `DC-015`)**: When the Owner issues subtractive directives (`只保留`, `去掉`, `砍掉`, `删除`, `严禁出现`, `ONLY keep`), `design.md`/`spec.md` MUST include an explicit **`Negative DOM/View Assertions` (`count == 0` / `!exists`)** section and a concrete **`Obsolete Test Manifest` (`file:line`)** (vague placeholders like `无破坏性旧单测删除` fail `design_contract.py --audit-spec` and `verify_design_cases.py audit-spec`). Never substitute a **Top-Stacked Duplicate/Focus Card (`IOSTopFocusTodoCard` + `其余待办`)** when the Owner asks for **In-Place Card Unfold (`列表原位置同一个卡片容器向下展开`)**. Freeze the winner into `design.md`, then immediately run `design_catalog.py cleanup-demo --goal <goal>` (also at Goal completion) to remove ephemeral handoff and blog demos.

**Two-Stage Demo Pipeline**: Stage 1 **Designer** (`--role designer` → `magpie/group/designer`, Copilot `gemini-4-argon` + `grok-4.7`) authors FOUR independent screen prompts or FOUR app-nav prompts: visual metaphor, one P0, P1/P2 folding, color/surface polarity, Liquid Glass optical parameters, inline SVG iconography, and explicit anti-patterns. ## Sub-mode 2 · Phase 1 Post-Implementation Visual Traceback (`B4 · 实现后截图回溯`)
`my-designer` operates as a **Dual-Touchpoint Closed Loop**: **Touchpoint 1** is Phase 0 ideation (`design.md`/`spec.md`), and **Touchpoint 2** is **Post-Implementation Visual Traceback (`实现后截图回溯`)** during Phase 1 independent review:
- **Writer low-cost screenshot capture**: After passing `shared-ci/scripts/context/design_contract.py` (`--audit-code`, `--audit-spec`, `--audit-l10n`, `--check-edge-clipping`, `--audit-geometry`) and `verify_design_cases.py` (`DC-012` no nested `Button` / locked `minHeight` drawer, `DC-014` `UI_INSTRUCTIONAL_CLUTTER`, `DC-015` no top-stacked duplicate card or unstripped dock mask, `audit-spec` subtractive gate, `--check-whitespace-ratio` `<=40%` `VISUAL_EXCESSIVE_DEAD_SPACE`, and subtree leaf AABB `--audit-geometry` `>2pt²` `GEOM_TEXT_COLLISION`), the `Writer` captures real full-viewport screenshots by platform (Apple: `XCTest` snapshot / `xcrun simctl io booted screenshot` / headless `ImageRenderer` 4 states × 2 appearances PNG; Web: Playwright headless screenshot) and records screenshot paths in the R10 receipt. **Writer is responsible ONLY for faithfully implementing declared constraints, never for guessing undeclared constraints.**
- **Independent Reviewer Visual Traceback (`[IMPL_BUG]` vs `[SPEC_GAP]`)**: The cross-vendor independent `Reviewer` loads `code-review` + `my-designer` to inspect both code diff and rendered screenshots from the R10 receipt, classifying every visual/interaction finding into:
  - **`[IMPL_BUG]` (Implementation Deviation)**: Writer violated an explicit clause in `design.md` or `design_contract.py` → route directly back to Writer to fix against existing `design.md`.
  - **`[SPEC_GAP]` (Phase 0 Spec Omission / Unforeseen Reality)**: Writer followed `design.md`, but rendered pixels expose crowding, CJK wrapping, column drift, or hierarchy conflict missed in Phase 0 → **NEVER blame Writer or ask Writer to guess undeclared rules**; route back to `Steering` to **amend `design.md` first (and re-stamp `spec_sha`)** with concrete parameters before dispatching Writer.
  - **Mandatory Reviewer Subtractive & Zero-Clutter Gate**:
    1. **Subtractive Exclusivity Check (`减法排他性必查`)**: Whenever the Owner specifies *"only keep X and Y"* (`只保留 X 和 Y`), if the rendered PNG exhibits ANY undeclared 3rd element class (e.g., residual `148pt` bottom gray mask, top append banner, 7 waveform dots, or bottom status text), the Reviewer MUST unconditionally fail (`[IMPL_BUG]` `FAIL`, or `[SPEC_GAP]` `FAIL` if retained by `design.md`) — never pass merely because X and Y exist!
    2. **Zero Instructional Micro-Copy Check (`零说明书废话必查`)**: If any screenshot prints tutorial/instructional micro-copy (`"点击XX修改"`, `"按XX继续追补"`, `"执行步骤树"`) or repeats self-proving feature hints `>1` time on screen, the Reviewer MUST immediately fail (`[IMPL_BUG]` / `[SPEC_GAP]` `FAIL`)!
- **Anti-Explosion Promotion Gate**: Every `[SPEC_GAP]` updates the current Goal's `design.md` (100%). Promote to Entry A (`verify_design_cases.py register-case --id auto`) or `shared-ci` (`design_contract.py`) via `skill_contract.py sink-rule` **ONLY when it is cross-project generic, free of private symbols, and recurring on the same container**.
