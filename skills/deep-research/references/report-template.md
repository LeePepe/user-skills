# Report Template

Phase 4 最终报告模板。按需裁剪(landscape 类换成分类矩阵),但**引用来源**与**局限性**两节永远保留。

```markdown
# 深度调研报告:{topic}

> 调研深度:{quick|standard|deep} · 渠道:{web/github/news/academic}
> 来源总数:{n} · 核查方式:{单模型自查 | 跨模型(codex/kimi/claude)}

## 📋 执行摘要
{3-5 句概括核心发现与最可信结论}

## 🔍 详细发现

### 1. {维度}
- 🟢 HIGH: {结论} — 来源 [1][2]
- 🟡 MEDIUM: {结论} — 来源 [3]
- 🔴 CONTESTED: {争议点};A 方称… [4],B 方称… [5];分歧未解,原因:{…}

### 2. {维度}
...

## 🏛️ 圆桌综合
{差异化视角的碰撞:各视角最核心的发现、相互矛盾处及原因、综合结论}

## ⚖️ 置信度总结
| 发现 | 置信度 | 独立来源数 | 核查 verdict | 备注 |
|------|--------|-----------|-------------|------|
| ...  | HIGH   | 3         | CONFIRMED   |      |
| ...  | CONTESTED | 2      | 分歧        | 见详细发现 |

## 📚 参考来源
### Web
1. [标题](URL) — 日期
### GitHub
1. [名称](URL) — ⭐ {stars} — 活跃/归档
### News
1. [标题](URL) — 媒体 — 日期
### Academic
1. [标题](URL) — 作者 — 年份

## ⚠️ 局限性 & 信息缺口
- {未能覆盖的方面}
- {未经独立/跨模型核查的发现 — 如有降级,如实列出}
- {搜索受限的渠道 — 如 bot 拦截切了 Wikipedia 兜底}
```

## landscape 变体

当问题是"某领域有哪些工具",把「详细发现」换成分类矩阵:

```markdown
## 🗺️ 生态矩阵
| 类别 | 工具 | ⭐ | 状态 | 融资/背景 | 与你的关系 |
|------|------|-----|------|----------|-----------|
| CLI agent | ... | 132k | 活跃 | ... | 竞品/互补/不同赛道 |

## 🎯 分诊
- **值得试**:{直接相关}
- **值得关注**:{潜在相关}
- **无关**:{不同赛道}

## 📉 整合信号
{近期归档的项目 = 赛道收敛信号}
```

## 写报告纪律

- 每个论断挂到具体来源编号,不留无引用断言。
- HIGH 必须 ≥2 独立来源;做不到就降级为 MEDIUM,别硬标 HIGH。
- CONTESTED 如实呈现争议双方,不替读者选边。
- 局限性别省——降级、未核查、搜索受限都要写出来,这是报告可信度的一部分。
